# ⚡ Hackme Suite - OSINT & Recon Platform

**Hackme Suite** is a Python-based OSINT and web reconnaissance toolkit developed by **Vedansh Srivastava**.

## 🚀 Features
- **Phone Number OSINT:** Identifies country/region, telecom carrier, and timezone.
- **Web Target Recon:** Fetches public IP, geolocation, hosting provider, and HTTP server headers.
- **Email Domain Lookup:** Validates domain and resolves mail host IP.
- **Community Links:** Quick access to ELVORIX, YouTube, Discord, and Telegram.
